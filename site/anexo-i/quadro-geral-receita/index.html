    Como ler este demonstrativo

    O código de nove posições é a classificação oficial da receita, usada em todo o país. Ele é hierárquico: os primeiros dígitos dizem a categoria econômica, os seguintes vão estreitando até o tipo exato de arrecadação.

    A mesma receita aparece em vários níveis com valores iguais: não é repetição, é o mesmo dinheiro visto com mais ou menos detalhe. Somar todas as linhas dá um número sem sentido -, some apenas as linhas de um mesmo nível.
